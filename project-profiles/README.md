# Profil Proyek

Satu folder per proyek: `project-profiles/<nama-proyek>/SKILLS.md`, dibuat oleh agent `scout` lewat `/scan-project <nama>`.

- `status: draft` = hasil scan otomatis, belum kamu konfirmasi. `confirmed` = sudah kamu periksa.
- Edit manual boleh, terutama bagian Guardrail dan Testing. Scan ulang tidak akan menimpa bagian Guardrail yang kamu tulis sendiri tanpa konfirmasi.
- Scan ulang disarankan saat: upgrade TFM (6 -> 8 -> 10), restrukturisasi project, atau ganti pola test.
- Tidak menyimpan secret. Connection string ditulis `<redacted>`.
